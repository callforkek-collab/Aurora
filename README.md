# Aurora — модули NWN 1, собранные из кода

Генератор модулей Neverwinter Nights 1 на Python (без зависимостей, Python 3.8+).
Полученный `.mod` открывается в Aurora Toolset.

## Пещера дракона

Маленькая стартовая пещера (тайлсет `tdm01`, «Шахты и пещеры», 6×6 тайлов).
Игрок появляется у входа, в глубине стоит дружелюбный красный дракон.
Если щёлкнуть по дракону, он скажет «Привет, путник!».

Готовые файлы лежат в `dist/`:

- `dragoncave.mod` — русский текст (кодировка cp1251, для русской версии игры);
- `dragoncave_en.mod` — английский текст (cp1252).

### Установка

Скопируйте `.mod` в папку модулей:

- EE: `Документы\Neverwinter Nights\modules`
- 1.69: `<папка игры>\modules`

Затем откройте его в тулсете: File → Open Module.

### Пересборка

```
python3 build_dragon_cave.py            # -> dist/dragoncave.mod
python3 build_dragon_cave.py --lang en  # -> dist/dragoncave_en.mod
```

## Что внутри модуля

| Ресурс | Назначение |
|---|---|
| `module.ifo` | свойства модуля, стартовая точка |
| `repute.fac` | 5 стандартных фракций |
| `dragoncave.are/.git/.gic` | локация, размещённый дракон, комментарии тулсета |
| `cave_dragon.utc` | шаблон дракона |
| `dragon_hello.dlg` | диалог приветствия |

Дракон использует стандартные AI-скрипты `nw_c2_default*`. Скрипт
`nw_c2_default4` (OnConversation) открывает диалог, указанный в поле
Conversation. Своих скриптов в модуле нет, поэтому компилировать ничего не нужно.

## Библиотека `nwnmod`

- `nwnmod/gff.py` — чтение и запись GFF V3.2 (ifo, are, git, utc, dlg и др.);
- `nwnmod/erf.py` — чтение и запись ERF V1.0 (mod, erf, hak).
